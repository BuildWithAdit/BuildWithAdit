### 🧠 About Me  
Hey, I’m **Adit** — a backend developer who believes great systems are built on **clarity, not chaos**.  
I work with **Java, Spring Boot, SQL, and Python**, crafting clean, dependable backends that scale quietly.

💼 Currently building:
- 🏛️ **Library Management System** – Java + MySQL backend with CRUD, role access, and modular design

### 🚀 Featured Projects  

#### 🏛️ Library Management System  
A clean, modular backend to handle books, users, and issue records.  
**Tech:** Java + MySQL  
**Highlights:** Relational DB design, optimized queries, maintainable structure.

#### 🎓 CU Events – University Event Platform  
A modern full-stack platform for students and organizers.  
**Tech:** React, TypeScript, Tailwind, Supabase  
**Features:**  
- Browse events across 8 categories  
- RSVP, like, comment, and earn badges  
- Real-time updates & secure auth  
- Beautiful gradient-based UI
